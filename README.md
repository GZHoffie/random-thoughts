# 想到啥写啥

- 世上无难事，只要肯放弃。
- 大家都说“听不见中提琴的声音”，确实如此。但我很喜欢中提琴声部：因为自己都听不见自己，反而能听清楚整个乐团的和声。
- 家人投资基金，买了就亏，卖了就涨，大叹“亏了”、“不该卖”。我说要这么想：**正是因为**你卖了，**所以**人家才能涨。这么一想，就释然了。
- 船到桥头自然沉。
- 所谓道德，也许其根本是源于对不道德的厌恶。没有道德固然不行。但若喜欢站在道德的制高点上，周围的便会充斥着不道德，进而引发对周围一切的厌恶。这是否又是另一种不道德呢？
- 大家总说古典音乐是“高雅艺术”，去听古典音乐会更是“高贵”。但是现在去听一场古典音乐会，甚至不用花一张流行音乐会门票的十分之一。更何况，每场演出都能听到上百人的绝妙配合。这性价比已经是不能更“大众”了！
- 旅行总要留点遗憾的。想要事事圆满，每个景点全部玩到，几乎不可能。如果为了面面俱到搞得自己很累，没法好好享受，反而是一种本末倒置了。留点遗憾，才有下一次旅行。
- 在有些领域，论文每次被当作baseline引用，就是被新方法打败了一次。所以引用越少，论文越强（狗头）。
- 读博对我来说最宝贵的，一是知道了我能力如何，二是知道了我到底喜欢什么。知道能力如何，就不用费力去追求超出自己能力的东西；知道自己喜欢什么，就学会了取悦自己，生活就有了依靠、有了盼头。
- 以前我对乐章间鼓掌的人嗤之以鼻，心里总会暗骂其破坏氛围。但一些更专业的人反而会觉得没事：鼓掌，说明是新听众；如果没有新听众，古典音乐就完蛋了。仔细一想，其实各行各业都是如此。

- 最近听了很多[小众作曲家的交响作品](https://www.youtube.com/@KuhlauDilfeng2/videos)，或者是大作家的小众作品，很多都惊为天人。历史长河里，在各个不同的领域或许已经有太多这样的宝藏，因运气不佳而被人遗忘。如今的AI不断拓展预训练数据，也许能重新拾起这些hidden gem，这么想就很欣慰了。

- 在openai/math发布之后，有人感到兴奋，有人感到厌恶，也有人感到恐惧。我个人感觉到的首先是同情：对于已经深挖这些数学、算法、理论问题许久的博士生、科学家，看到AI一夜之间就给出了答案，一篇文章只有OpenAI一个作者，该作何感想？其次是空虚：如果AI能轻松解决他们研究的问题，那也一定能轻松解决我研究的问题。那我的想法还有没有意义？我将来能去哪，又能干些什么呢？
